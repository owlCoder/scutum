## Pokretanje

Linux / WSL / Git Bash:

```bash
bash scripts/scutum.sh network      # jednom po računaru
bash scripts/scutum.sh up t04          # api + baza
curl http://localhost:8004/health  # očekivano: OK
bash scripts/scutum.sh test t04        # isto što radi CI
bash scripts/scutum.sh down t04        # dodajte --volumes da obrišete podatke baze
```

Windows PowerShell / Command Prompt:

```powershell
scripts\scutum.bat network
scripts\scutum.bat up t04
curl http://localhost:8004/health
scripts\scutum.bat test t04
scripts\scutum.bat down t04
```
